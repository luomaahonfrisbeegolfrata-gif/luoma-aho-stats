WORKFLOW AUTOMAATTI - MUSTA POHJA + PITUUS

TÄMÄ LUO .github/workflows KANSION JOKA PÄIVITTÄÄ AUTOMAATTISESTI

Mitä workflow tekee:
- Ajetaan joka päivä klo 08:00 Suomen aikaa (cron: 0 5 * * *)
- Ajaa scraper.py joka:
  * Hakee Pituudet automaattisesti fetch_pituus()
  * Generoi mustan PNG:n (musta pohja + Pituus rivi Väylä ja Par väliin)
  * Päivittää data/ratatilasto.json + vaylatilasto.json
- Committaa VAIN: data/ratatilasto.json, vaylatilasto.json, ratatilasto.png
- EI KOSKE KOSKAAN: index.html, js/, data/, README.md

ASENNUS:
1. Lataa koko tämän kansion sisältö GitHubiin "Upload files"
   - .github/workflows/auto-update.yml -> LUO KANSION .github/workflows
   - scraper.py -> juureen
   - data/ratatilasto.json, ratatilasto.png, js/ratatilasto.js -> kuten ennen

2. Mene GitHubissa Actions välilehti -> Enable workflows

3. Ensimmäinen ajo: Actions -> Auto-update ratatilasto -> Run workflow

Jatkossa päivittyy automaattisesti joka päivä, ilman että kosket mihinkään.

PAIKALLINEN PÄIVITYS (jos et halua odottaa):
python scraper.py

MUSTA POHJA + PITUUS:
- Kuva: musta tausta #000, valkoinen teksti, värit Avg/Difficulty
- Pituus rivi: Väylä ja Par väliin, haetaan fetch_pituus() -> [125,103,72,57,94,96,103,80,116,85,197,120] = 1248m
- Automaattisesti päivittyvä kun rata muuttuu, vaihda fetch_pituus() funktiota scraper.py:ssä
